# SnakeYes
Snake Yes — аркадная змейка на Godot написанная нейросетью, порт под ПК + мобильные (альбомная). Меню с темами Light/Dark, флажком и кнопками. Игра: поле 10×10 из песчаных тайлов с обводкой и 3D-гранью, дискретное движение (1 клетка = 1 часть), яблоки со звёздочками и случайным звуком, падение поля при старте с пылью и тряской, сообщения «you win!!»/«you lose!!», полный набор звуков.

# 🐍 Snake Yes

Аркадная змейка на **Godot 4.7** с песчаным полем.
Проект нацелен на **ПК и мобильные устройства** (альбомная ориентация,
настройки экспорта появятся позже).

## Запуск

1. Установи Godot 4.7 (подойдёт Steam-версия).
2. Открой папку проекта (`project.godot`) в Godot.
3. Нажми ▶ (F5) — старт с главного меню.

## Управление

Поворот змейки - WASD / стрелочки
Свайп - палец или мышь (эмуляция тача включена)
Начало движения - первое нажатие направления

Змейка не двигается, пока игрок не нажмёт направление. Разворот на 180° запрещён.

## Игровой цикл

- Поле 10×10 из песчаных тайлов с обводкой по краям и 3D-гранью снизу,
  голубой фон.
- При старте **поле падает с неба**: приземляется с облачками пыли,
  отскоком и лёгкой тряской.
- Яблоко съедается с эффектом **разлетающихся звёздочек** и звуком
  (еда1/еда2 — случайный). Змейка растёт с хвоста.
- Выезд за поле (на голубое) или врезание в себя — **«you lose!!»**,
  змейка исчезает с головы до хвоста с вспышками.
- Заполнил всё поле — **«you win!!»** и возврат в меню.

## Главное меню

- Фон Light/Dark с плавным кроссфейдом (кнопка справа сверху).
- Флажок сверху падает с bounce-эффектом и тянется за курсором;
  каждый вход в меню — новый случайный флажок.
- Кнопки «Играть / Магазин / Скины» (магазин и скины — заготовки).

## Структура проекта

```
scenes/    game.tscn — игровая сцена, main_menu.tscn — меню
scripts/   game.gd — вся логика игры, main_menu.gd — меню,
           theme_manager.gd — autoload тем (Light/Dark)
assets/    Field (выпеченное поле board.png), Apple, Snakes, Effects
           (звёзды, пыль), UI (win_text), fonts (шрифт примера),
           sfx (звуки), BG, Buttons, Flag
```

Звук: `еда1`/`еда2` — при поедании (случайно), `проигрыш` — при смерти,
`победа` — при полном поле, `поворот` — при смене направления.

## Технические заметки

- Рендер: поле выпечено в одну текстуру `assets/Field/board.png`
  (тайлы + обводка + 3D-грань) — один спрайт вместо ~140 узлов.
- Движение дискретное: 1 клетка = 1 спрайт-часть змейки, тик 0.3 с.
- Управление читает `physical_keycode` — WASD работает на любой раскладке.
